== Product model (decoupled index)

Sessions are **real OS windows**. A separate **calling / index window** tracks them as tabs and/or a thumbnail grid. Tabs are **not** glued to the PTY surface (unlike classic Windows Terminal).

----
+---------------------------+          +------------------+
|  CALLING / INDEX WINDOW   |          | SESSION WINDOW B |
|  tabs  and/or  thumb grid |  owns    |  PTY + vt cells  |
|  (chrome / session index) | -------> |  (live surface)  |
+---------------------------+          +------------------+
         |                                      ^
         |                                      |
         +---------> SESSION WINDOW C ----------+
                     (another OS window)
----

Canonical detail: link:docs/PRODUCT-MODEL.adoc[docs/PRODUCT-MODEL.adoc].
Prior dlangui "window piping" implementation: **NOT FOUND** -- see link:docs/WINDOW-PIPING.adoc[WINDOW-PIPING.adoc].

== Stack

|===
| Piece | Role

| `pty-d`
| ConPTY / POSIX PTY bindings

| `vt-d`
| VT/ANSI to character-cell screen

| `dew` + `vello-d`
| Host chrome, DPI (`dew.scale`), GPU paint

| `dui`
| App-kit (state/forms) when chrome grows

| Consolas
| Curated cell font (Open Shell / shell-architecture typography)
|===

== Build

Headless cell spike (always; no GPU):

[source,powershell]
----
dub run -c spike-cells
----

Pane spike (GLFW + dew GPU; needs Rust/`cargo` for vello-d bridge + sibling checkouts):

[source,powershell]
----
dub run -c spike-pane
----

----
github.com/
  openshellorg/open-terminal/     (this)
  ../dlang-supplemental/{dew,dui,vello-d,pty-d,vt-d}/
----

== Relationship to WT fork

* **Keep** `openshellorg/terminal` for near-term env-refresh + host-chrome negotiation.
* **Grow** this repo for decoupled multi-window UX + whole-UI scale.
